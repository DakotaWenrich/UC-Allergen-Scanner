# UC-Allergen-Scanner: Options A, B, C

## A. Prototype (app.py)
Run: `pip install -r requirements.txt` then `streamlit run app.py`.

## B. Figma screens (build these 6 frames, 390x844)
1. Welcome + disclaimer
2. Profile setup (condition, flare/remission toggle, allergies, custom triggers)
3. Camera capture (label vs. meal toggle)
4. Analyzing (loading state, "reading label...")
5. Result: big green/yellow/red badge, confidence %, allergen chips, trigger list with reasons
6. Safer swaps + save to history
Show the user journey as arrows between frames and label where AI acts (OCR/vision, risk scoring, confidence).

## C. 3-minute video script
- 0:00-0:30 Problem: living with UC/Crohn's, reading labels is stressful, apps only flag top allergens.
- 0:30-1:00 Insight: carrageenan, polysorbate 80, sweeteners etc. are hidden triggers.
- 1:00-2:15 Demo: screen-record the app scanning a label and a meal; cut in the Figma screens.
- 2:15-2:45 AI-native: vision + personalization by flare phase + confidence scores.
- 2:45-3:00 Impact + safety: fewer flare-ups, less food anxiety; not medical advice.
Tools: generate the problem scene with an AI video/image tool, voiceover with an AI voice tool.
